# Zorvyn_frontend_assignment

### A High-Fidelity, Professional-Grade Trading Console

Zorvyn Finance Terminal is a **modern fintech dashboard engineered for serious traders and investors**. Built with **React 19**, it replicates the precision, speed, and visual clarity of industry-grade platforms like Zerodha and Stripe—delivering a seamless, high-performance experience across all devices.

---

##  Live Experience

> *Designed to feel like a real trading desk — fast, responsive, and data-rich.*

---

##  Why This Project Stands Out

### 1️. Universal Device Adaptability (Mobile-First Architecture)

* Custom **4-tier responsive system** (Desktop → Laptop → Tablet → Mobile)
* Fluid grid + advanced media queries for **adaptive layouts**
* Seamlessly transforms from a multi-column **“War Room” dashboard** to a clean mobile UI

 **Achievement:**

* Zero horizontal overflow even for large datasets
* Implemented **custom swipeable containers (webkit-based)** for smooth mobile navigation

---

### 2️. Role-Based Access Control (RBAC) Simulation

A realistic dual-role system replicating production-grade fintech access control:

*  **Admin Role**

  * Execute Buy/Sell orders
  * Full state control & transaction updates

*  **Viewer Role**

  * Read-only access
  * Monitor portfolio & market trends

⚙️ **Tech Implementation:**

* Managed via **React Context API**
* Ensures **global, synchronized role-based state handling**

---

### 3️. Premium Engineering & UI/UX Design

####  Architecture

* Component-driven development
* Clean separation of concerns
* Scalable and maintainable codebase

####  UI/UX

* Stripe-inspired **Dynamic Glassmorphism login UI**
